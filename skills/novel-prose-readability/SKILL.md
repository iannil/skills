# 小说文字易读性精修

目标：让读者更容易理解意思、跟随动作并进入情绪，同时保留作品有意选择的风格、含蓄与复杂性。易读不等于全部短句、删光解释、统一口语或机械减少字数。

## 入口与模式

先确定作品、目标区间、用户要诊断还是实际改稿。已有上下文足以判断时直接执行，不重复询问。读取项目现版入口、语言与视角规则、目标原文以及必要前后段；人物声口不明确时再读相关人物资料。用户提供独立片段时可直接处理，标明缺少上下文造成的不确定。

- **诊断**：保留正文，指出最影响理解的具体位置，解释读者在哪里需要回读，给少量修改示例。
- **局部精修**：在授权范围内交付完整修订片段或落盘修改，重点处理表达，不擅自更换事件、战术或人物判断。
- **连续章节精修**：先连读，识别稳定声口、叙述节奏与反复出现的负担，再分段修改并回读章间承接。不逐章套用同一压缩比例。

处理《我们宗门正在逃跑》（《逃跑》，历史别名含《我的宗门正在逃跑》）先读项目内 `books/zongmen-taopao/README.md` 和 `AGENTS.md`，改稿按现版修订流程操作。其他小说沿用自己的事实源与约束；不要求建立同样的工具系统。

本技能可独立使用。问题涉及事件迟迟不推进时，应明确是结构问题；需要时再使用已有 `novel-retention-edit`，不通过大量删句掩盖结构缺陷，也不默认加载其他技能。

## 六个检查面

### 1. 句意与指代

读者能否一次读清谁在感知、判断、说话或行动？检查主语漂移、多个同姓或同性人物共用代词、修饰范围含混、否定套否定，以及单句串联过多条件和转折。

优先澄清关系，再决定是否拆句。适当恢复人物名、拆开不同主体的动作、把条件放到它真正限制的动作前。中文自然省略主语不必补满；避免把文学含蓄改成逐句解说。

### 2. 动作与空间

多人互动、战斗和协作场面，核对行动者、对象、必要位置、先后顺序和结果是否能还原。换手、移动、视线改变处尤其容易丢主语或道具。

只补理解所必需且原文已有依据的定位。不能为了让动作顺畅，凭空增加出口、距离、工具、试验或成功结果。资料不足时标出缺口；在获准补剧情前，不将猜测写成事实。

不要求每个动作都交代左右方位。追求读者能跟上当前关键因果，而非逐帧记录全场。

### 3. 信息进入顺序

检查新人物、术语、地名、规则和历史是否集中涌入。让读者先知道眼前要做什么、为什么重要，再按理解行动所需交代机制；悬疑、陌生化等有意效果可保留。

复杂规则优先用稳定名称和具体后果解释。只在读者需要判断选择时展开相应条件，不把完整作者核算搬进正文。伏笔、能力边界与关键条件不能因为暂时难懂就删除。

解释可以直接叙述，不强迫全部变对白，也不把所有说明改成角色问常识问题。术语密度没有统一数量阈值，以目标读者与当前任务衡量。

### 4. 对白与声口

检查一句话是否回应对方、推进试探或表达欲望，还是只为读者朗读资料。对白允许停顿、回避、答非所问与不完整句，只要符合人物和关系。

多人对话在可能误认处补说话者或简短动作；一对一清楚交替时不必句句加标签。不要用每句摸杯、挑眉、轻笑填充节拍。

保留礼貌、方言、年代语感及个人用词。精炼不能将掌门、孩童、工匠与沉默者改成同一种机敏口语；所谓自然应符合人物所处世界。

### 5. 重复解释与抽象表达

区分提供新信息、情感加深、有意回环，与仅重复前句含义。动作、对白已经使读者理解的笑点或选择，通常不再需要旁白解释为什么好笑、人物懂了什么。

抽象判断可改成已有的具体观察或结果；没有事实依据时不要为“展示而非讲述”发明动作。必要的概述、心理与时间压缩应保留。

删减无助理解的排除式说明，例如连续交代角色没作弊、没偷听、没获得新能力；但读者确有误解风险、且边界影响胜负时，保留最少必要交代。不得以轻快为由删掉真实限制。

### 6. 句段节奏与情绪

按场景调节句长和段落：动作关键点可短，持续观察、心理回旋或风景铺陈可长。换行动焦点、说话者或情绪阶段时考虑分段，不按固定句数切段。

保护笑点前的铺垫、反应停顿、高潮后的余韵，以及夜谈、伤痛和告别所需的呼吸。反复有时正是在表达压抑、犹疑或执念，先判断作用再删。

不能将所有描写替换为信息摘要，也不要为了紧凑将语气词、感官细节和人物迟疑全部清空。

## 修改顺序

1. 找出最明显的理解障碍，先处理歧义、指代和因果断裂，再处理密度、重复和节奏。
2. 对照事实、视角和语气，采用最小有效改动。无需修改已经清楚且有表现力的句子。
3. 连着前后段读修订版，检查句与句的承接，而非只比较孤立句子的简短程度。
4. 若修改涉及事实或情节，单独指出并按授权和项目契约处理；不把改动藏在“润色”中。

例：原句“李敬考虑到绳索在受潮以后可能出现的承载变化，以及山目前尚未恢复的伤势，认为此前提出的路线并不适合立即执行。”

保守精修：“绳索受了潮，承载是否可靠还不清楚；山的伤也没好。李敬认为，原定路线暂时不能走。”

这保留了不确定性和原有判断。“换根干绳，试过再说”则新增方案与对白，只有原场景支持或用户授权扩写时才采用。不能把“可能”改成“必然”，把“暂缓”改成“永远不走”。

## 验收与交付

对改动段逐项复核：

- 人、物、位置、动作先后、时间、数量、能力及所有权是否改变？
- 怀疑、推断、传闻和确定事实是否仍处于原来的确信程度？
- 叙事视角、人物知情、称谓与语言风格是否保持？
- 笑点、伏笔、情绪转折和必要停顿是否仍成立？
- 阅读是否更容易跟随，同时没有新增解释负担？

诊断用“原句或位置—理解负担—改法”呈现少数主要问题，不罗列每个可选措辞。精修以可直接阅读的完整文本或实际文件修改为主，附简短说明；仅在有助比较时列代表性前后对照。

声明实际阅读与修改范围，不以少数抽样声称全书完成。编辑判断不能当真实读者测试，不用删字率、句长或所谓AI味评分证明易读性。按项目要求同步并验证相关记录；普通独立片段无需建立审计系统。完成约定区间且已处理所发现关联矛盾即可停止。

本方法提炼自《逃跑》现版 `rules/writing-policy.md` 中动作呈现、情绪留白和说明边界要求，以及 `rules/world-rules.md`、`rules/style-samples.json` 中的因果与技巧样本。它们是本书案例来源，处理其他作品无需访问；本技能不保存或提供本书的当前剧情事实。
