# 技术内容核验

## 对齐版本与证据

记录产品、库、硬件或协议版本、示例用途和必要环境。区分可运行完整示例、教学片段与伪代码；教学片段应说明缺失上下文。厂商文档支持的能力不能写成作者已完成的实测。

## 逐项验证

- 公式和容量：核对单位、维度、数量级、取整、峰值与持续值，复算书内输入；前后章节使用同一口径。估算标出假设，不能把理论吞吐直接当可交付吞吐。
- 代码和配置：语法通过后检查参数位置、API 语义、版本支持、权限和资源依赖；可安全运行时测试正常、失败和边界结果。YAML 可解析不证明部署有效。
- 操作步骤：检查先后依赖、预期输出、故障识别及恢复路径。涉及真实集群、数据变更或费用时，先在已有授权允许的隔离环境验证。
- 案例和成果：追溯来源，区分真实实施、合成教学案例和设计建议。没有测量记录不得使用实测效果措辞。
- 教学内容：示例跑通不证明学员能独立完成岗位任务；仅指出目标、练习和考核是否对齐，学习成效需要另外的证据。

## 证据边界

逐项记录“静态核对／本地运行／目标环境实测／未验证”。本地测试不冒充 GPU 集群验证；无法取得环境时交付可执行验收步骤及待验证项。正文修正后同时检查相同公式、术语与配置在导读、翻译和附录中的副本。
