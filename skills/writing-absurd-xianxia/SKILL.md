# 离谱成仙：荒诞修仙喜剧爽文

让三个承诺同时兑现：**设定让人觉得“这也行？”，推演让人觉得“还真只能这样”，结算让人觉得“还能这样，赢麻了”。**

让脑洞贯穿正文，让反转推动行动，让笑点加强胜利：荒诞规则制造困局，人物认真办事，对手聪明反制，破局同时产出反转、笑点和保留的胜果。

## 定位与边界

- 综合写作入口是 `write-webnovel`，喜剧基础机制见 `novel-comedy-engine`，反转公平性见 `novel-reveal-design`，智谋结算见 `novel-tactical-payoff`。本技能承接它们的共同原则，专攻"荒诞规则、反反套路、笑爽反转同时兑现"三件事，可独立使用，不要求同时加载其他技能。
- 核心事件由修仙机制驱动：神识、境界、法宝、天劫、因果等实际影响行动和结果。替换这些机制而核心情节丝毫不变时，重审设定与行动的联系；普通日常笑话仍可用于关系与换气。
- 方法可迁移到其他高设定题材，但只在用户明确要求时使用；默认只服务修仙。新作不自动继承其他作品的人物、境界或专有设定；续写用户指定作品时保留该作品现版内容。
- 分析请求不改正文；用户明确授权后才动稿。写稿不自动授权发布或提交。

## 确定本次契约

读取用户提供的设定、正文或需求，确认：模式（脑洞构思／故事设计／正文续写／审读改稿）、题材口味强度（默认爆笑+爽，可调向冷幽默或更严肃）、篇幅（单章/单元/长篇规划）。

- 保留用户给定的世界规则与既定事实；用户明确授权重设时才改变。新作缺口采用明确假设并简短声明，只追问会改变方向的关键问题。旧稿缺口保留为未知，准备新增的条件标为待补铺垫。
- 已有正文续写时，先核对该作品现行规则、人物知识边界和未回收伏笔，新反转不得偷偷改变已明确发生的事实。
- 续写与审读时按需参考对应作品的项目入口与登记要求；无项目约定时不预设。

## 核心流程：预期 → 规则 → 人物 → 对手 → 破局 → 兑现

每步输出供后续使用，正文模式在内部完成后交付场景。

### 1. 找读者预期

列出场面的常规写法和老读者见过的反套路写法，作为接下来要偏转的靶子。例：夺舍=残魂强抢；秘境=捡宝结缘；天劫=硬扛通过。没识别出预期就先别设计反转。

### 2. 定荒诞核心规则

每个核心脑洞是一个**有边界的异想规则**，构思时用六问检验；向用户展示的详略服从任务和篇幅：

1. **为什么成立**：在世界观内说得通的原理（哪怕是歪理）。
2. **适用范围**：对谁、在什么条件下生效。
3. **代价**：使用者付出什么，越离谱的规则代价越要认真对待。
4. **不能做什么**：规则做不到的事，破局空间常藏在这里。
5. **连锁后果**：这条规则被普遍知道后，宗门、市场、战争、飞升会变成什么样。
6. **强者为何没用尽**：资源更厚的势力为何没有把它推到极限。

优先一个深规则生多个连锁，而非十个互不相干的怪点子。规则一旦立下，本单元内不得为情节方便临时加戏；新信息可以是"以前没暴露的细节"，不能是"性质变了"。

### 3. 让人物认真逐利

主角有具体目标、可用能力和盲点；配角各有小算盘；每个人按自己的理性行动，荒唐来自方法与现实相撞。主角可出丑，关键成果必须靠其判断或行动取得。人物失误应来自欲望、未知条件或判断偏差；让不同人物保留不同声口，避免靠降智、全员嘴贫或现代热词换皮制造喜剧。

### 4. 对手会反制反套路

常规解法失败后，聪明对手会预判"主角们惯用的反套路"并提前布防——**这层"反反套路"是本技能的招牌**。对手反制基于其已知信息，合理不等于全知；反制本身也制造新的可利用条件。

### 5. 破局用已立条件

主角的解法必须使用第 2、3、4 步已确立的规则、性格和布防，配合真实动作、准备和代价。禁止靠运气巧合、临时新规则、对手停手听解释成立。

按对手当下能力试推最直接的反制：毁掉仪式载体、控制施术者、转移人质，而非只重复主角预料的动作。低阶小术能争取局部窗口，但不能凭“强者看不起”就自动抵消高阶控制；需要已展示的遮蔽、距离、互斥动作或利益约束。

### 6. 笑、爽、反转一起结算

理想破局同时产出三样：对手具体企图落空（爽）、意外但必然的喜剧后果（笑）、保留可继续使用的成果（爽的延续）。反转改变目标、身份意义或胜负条件，不只是连续说"其实不是"。

## 反转设计：翻几层都行，翻完要能回看

- 每层反转前先固定作者真相，再安排各方误判；揭晓后旧细节仍真实，只是获得新意义。伏笔要能在揭晓处回看成立。
- 反转分别作用在不同层面——动机、策略、身份、意义、胜负条件——避免连续否定同一层。
- 跨单元检查最近使用的笑法、反转维度和胜利方式。世界与对手会记住旧招，主角成长后换挑战与解法；不把所有事件写成误会流、契约漏洞或装弱打脸。
- 长篇不要求章章多翻；一个完整事件连翻几次，事件之间留铺垫、兑现和回味。
- 每次反转都要改变读者下一段关心的问题，否则只是延迟揭晓。

## 喜剧与爽感守则

- 笑点落在选择、对白、动作和后果里，落完不解释"为什么好笑"；铺垫让读者理解人物想要什么。
- 让不同人物有不同声口与速度：认真者按流程办事、安静者一本正经、爱面子者嘴硬，都是强反差素材。
- 主角赢得要痛快：击破对手的具体企图、拿到实在收益、下一章有新筹码。新麻烦可以来，不例行清零奖励。
- 伤痛与情绪节点允许喜剧暂退，不用尾句笑话冲掉刚付的代价。
- "爆笑"是目标不是证据：判断用"此处预期与反差是什么"的编辑眼光，不宣称读者必然发笑。

## 审读改稿

诊断先于改动。先分开用户要求保留的规则和事实、用户明确点名要修正的错误段落、准备新加的条件。待修错误不是不可变事实；飞剑不自动等于本命剑，分身挡伤若仍传回本体就不自动获得减伤。对不够离谱、不够好笑、不够爽、反转太硬的旧稿，按"具体位置—问题机制—影响—改法"交付：

| 症状 | 常见根因 | 改法方向 |
|---|---|---|
| 反转太硬 | 揭晓依赖此前毫无依据的信息 | 补埋可回看伏笔，或换用已有条件翻 |
| 离谱但不合理 | 规则无代价、无边界、强者缺位无解释 | 补六问，重设适用范围与代价 |
| 不好笑 | 全员嘴贫、降智、热词堆砌 | 回到人物欲望与处境错位重组包袱 |
| 不爽 | 胜果被清零、主角被动、围观惊叹替代实际所得 | 让对手企图具体落空，成果可延续 |
| 设定临时翻案 | 为解决眼前的坑新加规则 | 用已立规则重解，或补此前线索 |

改稿后复读直接承接处，确认新解释与已发生事实兼容。约定问题解决即结束，不无限微调。

## 交付

- 脑洞构思：核心规则六问、人物冲突、连锁后果、连载潜力，可附多方案比较。
- 故事设计：各方目标信息表、事件链、反转层次、伏笔位置、结算。
- 正文：以场景交付，人物行动、对白、兑现与下一章期待；不交机制说明代替正文。交付前逐项核对用户指定角色、合作关系、争取的物品或人物、能力限制、篇幅与禁用设定。指定同伴应实际参与关键行动；明确取回的是哪件目标物，不能用另得奖励冒充完成原目标。关键学习盲区或阵法失效条件在破局前展示。
- 审读：问题清单加改法；授权改稿时交修改后正文并复核承接。
- 分开说明设计成立与正文已兑现，编辑判断不冒充读者实测或商业成绩。
