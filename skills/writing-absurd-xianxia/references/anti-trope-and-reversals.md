# 反反套路与多层反转

## 先固定真相，再制造解释

用一张小表区分：作者确定的事实、读者已见证据、主角知道什么、对手知道什么、外界传言。信息传播要有亲历、交谈、观察或推断来源；推断可能错，不能全员自动共享答案。

每次揭晓填写：旧预期 → 已有证据 → 当时合理解释 → 新证据或主动行动 → 新解释 → 下一步变化。不能填写已有证据时，先补铺垫或降低反转幅度。

## 四个层次，不是四个必填桥段

- 常规：类型经验让读者以为事情会怎样。
- 反套路：人物做出不同选择，或设定允许不同结果。
- 反反套路：对手预判这种聪明办法，利用它反制。读者熟悉的“意外”也成为局中人能想到的策略。
- 再破局：主角发现反制附带的限制，利用已展示条件创造第三条路。

“我早就知道你早就知道”不算行动。每层都要落在抢占位置、转移资源、试探能力、交换利益、改变目标等可见行为上。反制可以由制度、环境或配角利益触发，不必次次有幕后全知黑手。

## 让反转换一个维度

| 维度 | 可改变什么 | 应保留什么 |
|---|---|---|
| 动机 | 救人者为何救，敌人真正怕什么 | 已做的行为与付出的代价 |
| 策略 | 诱饵、目标、时机的理解 | 已展示能力和行动顺序 |
| 身份 | 一个身份的责任、用途和关系 | 已确认的事实，不反复推翻同一身份 |
| 因果 | 谁利用谁，哪件事引发了哪件事 | 可回看线索与时间先后 |
| 胜负条件 | 必须杀敌变成抢回物品或救人 | 如实命名战果，逃脱不冒充击败 |
| 意义 | 原本可笑的行为成为关键贡献 | 人物原始欲望与真实功绩 |

一次事件选能相互推动的几层。连续揭晓之间穿插人物判断与行动，让读者有机会形成新预期；不要用一段旁白连续宣布五个秘密。

## 高潮检查

主角先前的选择是否必要？对手合理反制是否真的发生？隐藏准备能否回认？最终解法是否超出能力？新解释是否保留旧事实？揭晓之后关系、行动或资源是否发生变化？

若反转取消了全部成长，优先改成揭示胜利的另一层价值或后果。若最后还要翻，先给已经成立的胜利足够篇幅，避免“原来一切都是梦、局、假奖励”。
