# 端到端验证

先确定关键用户结果与真实链路，沿用项目启动及就绪检查。现有服务可复用；只停止本轮启动且仍由本轮拥有的服务，不关闭用户其他任务。

有可用浏览器技能（如 agent-browser）时按其工具约定驱动交互；否则使用当前可用浏览器工具或报告限制。验证可观察结果和持久状态，不只检查按钮出现。刷新恢复、多角色权限或失败重试仅在相关场景加入。

截图、记录和数据保存在项目约定位置；隔离测试账号，凭据不写入公开报告。外部通知、付款等副作用使用已授权测试环境。模拟成功明确标模拟。

API 项目使用 HTTP 黑盒链路，CLI 检查命令输出、退出码和结果文件，库项目可用独立消费者集成测试。具体链路来自实际需求，不强制所有项目都有 CRUD。

偶发失败可在解释原因后有限复跑，记录首轮失败和重试结果，避免盲目重复有副作用步骤。服务无法启动时继续独立检查，但必需链路保持 UNVERIFIED；可复现的产品启动缺陷则记 NEEDS_FIX。
