## 保留、推广与排除

**直接保留的已确认方法**：五问审读；不等待百章后才改善阅读；授权后可以修订已写正文；人物成长不能抹平欲望；配角通过主动行为留下记忆；允许张扬成功；胜利要兑现；后续期待从实际结果产生。

**作为可选技法推广**：表层被动、底层主动；欲望引发的群像喜剧；窄而可靠的贡献建立强者合作；谜底翻转解释但保留关键事实；多感官临场感（按场景选 2–3 个主导感官，不凑满五觉）；节拍表与冲突生成器、动作密度自检（构思与修订工具，非写作配额）。它们适用于相应人物和类型，不是所有网文必须采用的套路。

**排除的历史或专属内容**：旧章号、固定的保留前若干章建议、已被修订的篇幅配额、具体人物术法与关系禁令、固定角色数量、收入估值及平台单价。写作工具和 JSON 审计契约仅在《逃跑》适配中使用。

**方法的证据限度**：这是根据一部作品持续编辑形成的实用技能；“读者可能想停”的位置是有原文依据的编辑判断。实际追更与付费效果仍需真实读者数据，不能从结构校验、五问通过或完整规划推导收入保证。

校准：动作数量、字数、章数及情绪四角度均为作者启发式，不是实测阈值或已核验心理学模型；不保留“读者永远正确”“可以不顾逻辑”“压抑越狠越爽”“最多三个视角”及固定反转频次等绝对化断言。十序列为可选危机成长模板，需求分类不要求逐层满足；不据这些方法承诺签约、收入或读者留存。
