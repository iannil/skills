# 故事与场景方法

## 单元与场景卡

先决定本单元带来什么不可轻易撤销的变化，再安排场景。篇幅由独特的冲突与变化支撑，不按预定总字数均摊手续。

可按需要使用以下小卡，不强制每场填写所有字段：

- 读者正在等的具体结果：
- 视角人物此刻想要什么、已知道什么：
- 他先做的动作；别人自己的打算：
- 限制与选择，所用能力及已建立的依据：
- 结果：得到、失去、关系变化或新知，哪些保留下来：
- 情绪停留：如何让人物和读者感到这次结果：
- 下一步由哪个结果触发；尚未兑现的承诺何时处理：

若相邻卡只是“再问一次、再验一次、再交接一次”，先检查这些步骤是否真的改变选择。能在一个场景中发生的不要拆成数章同一种等待。反之，不能把一次重要选择及其情绪全部压缩成结算摘要。

## 人物可记忆性

检查“去掉姓名后，这个动作还能分辨是谁做的吗”。答案依靠欲望、方法、关系和承担，而非口头禅数量。

| 想保留的特点 | 可见行动 | 容易写平的替代物 |
| --- | --- | --- |
| 好胜、张扬 | 主动争取一次公开表现，准备后真赢，享受掌声 | 一露头就挨训，最后学会不争 |
| 要面子 | 用自己的手段挽回场面，因此改变局势或欠下具体人情 | 只负责吹牛，被别人戳穿 |
| 安静、谨慎 | 看出别人忽略的事，自己承担一项决定 | 每场只说“稳妥些” |
| 善良 | 为具体的人付出时间、资源或机会，并尊重对方选择 | 发表正确观点，成本由别人承担 |
| 可靠 | 带着自己的欲望帮助大家做成事，接受别人的判断 | 成为调度员，没有个人生活与冒险 |

这些是选择工具，不要求每部作品照搬人物类型。人物缺点可以带来麻烦，也可以在合适环境成为优势；不必每次都接受道德纠正。

## 表面被迫、实际主动（可选）

适合口是心非、爱面子或擅长借势的人物：

1. 先呈现他自己的目的或微小准备，足以回看验证，不必立刻揭底。
2. 他安排条件或抓住机会，让别人的真实需要与自己的目的交汇。
3. 对方提出有限请求；他承担一个自己能做、愿意做的环节。
4. 当场行动有效，结果也满足他的欲望。笑点可以落在姿态，爽点落在改变结果。

不能让所有偶然都追认成布局。早期可以骗过旁人，后来同伴看穿仍配合，成熟后也可以公开争取；不能无限重复“推辞—大家求他—勉强成功”。

## 获得合作与权威

区分三种关系：同伴授权、强者基于自身利益合作、敌人受局势所迫取舍。它们不能一律写成听主角指挥。

- 让主角先解决一个小而关键的问题：准确判断时机、承认错误、给出可验证的信号、替别人承担实际成本。
- 合作有范围、条件和终止点；更强者仍能反对、修正、退出。
- 后来的认可回指具体贡献；别人独立使用他留下的方法，比一串赞美更有力。
- 修为或实力差距不靠话术消失。主角可以提供必要的小部分，其他人完成各自不可替代的部分。

## 喜剧与爽感（适合喜剧作品时使用）

小欲望 → 合乎此人性格的荒唐办法 → 别人各怀合理目的加入 → 局势升级 → 真正结果。

先问“只有这个人物组合和世界条件才会闹成这样吗”。如果随便换成普通宿舍或办公室也完全成立，考虑让世界能力、规模、限制与人物欲望进入因果，而非给笑话换玄幻名词。

不要在每个笑点起势时插入劝止与规则解释。规则通过行动后果体现。也不要强迫每场成功立即翻车：让爱出风头的人有一次漂亮出风头，让荒唐办法确实解决一个难题。

## 胜利、谜底和情绪

- 胜利：战果落地 → 人物使用或享受 → 他人反应或关系变化 → 新选择。可以有代价，避免所有收益刚到手即被收回。
- 对抗：对手有真实目标；被击败时损失与冲突规模相称，不总以理解、道歉或补偿消解。
- 谜底：区分客观事件与人物解释。翻转解释要能重读旧证据；若核心卖点依赖真实力量，别用“全是假的”一笔取消。
- 揭秘之后应改变行动、能力使用、关系或判断，不能永远只是获得下一张待核对的线索。
- 读者已知不等于路人已知。听传闻、亲眼看见、第一次听它说话可触发不同反应；惊讶要影响站位、动作或决定，不只写感叹词。
- 保留夜谈、饭后闲坐、相互照顾等低强度场景，只要它们改变亲近程度、人物选择或读者理解。节奏变化不是永久加速。

## 期待的变化

连续阅读时轮换真正的阅读任务：看对手误判、等比赛结果、想知道一段关系如何说开、想看新能力怎样用、带着不完整信息行动、期待人物兑现自己的愿望。不要只是轮换地名、敌人或道具，实际仍反复“准备充分才能开始”。

章尾检验：拿掉最后一句神秘预告，前面的结果是否仍让人想知道接下来怎样？若完全没有，优先修事件因果，不是再加一句“他不知道，更大的危险正在逼近”。
