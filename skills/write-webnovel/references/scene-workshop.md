# 场景工作台

用于需要完整细纲、示例或练习的任务。已有场景顺畅时不必填表；交付仍以用户要求的正文或修订为主。

## 从愿望到故事

记录一个具体的遗憾、愿望或触动 → 确认想获得的体验 → 转成角色目标 → 找出他人目标与现实限制 → 设计有代价的选择 → 安排可见兑现。作者有感受只是素材入口，不保证读者共鸣；角色可以与作者不同。金手指需要来源、范围和限制，不能替代因果。

例如“想让母亲不再劳累”可转成“按约完成订单，同时陪母亲就诊”。阻力是顾客的交期、母亲的信用顾虑与主角能力有限；选择是少接急单并协商交期。兑现是如期就诊和母亲自主决定下一周工作量，而非旁白说主角孝顺。

## 可选完整场景卡

- 阅读承诺与场景用途：
- 视角人物的目标、身份、能力边界、在乎或恐惧之物：
- 人物、读者各自已知的信息：
- 其他人物各自的目标与手段：
- 限制、自然期限与可选办法：
- 节点：刺激或发现 → 如何理解／感到什么 → 选择与动作 → 反馈／新认识：
- 结束状态：局势、关系、认知或选择改变了什么：
- 情绪余韵与下一步：哪些承诺兑现，什么结果触发后续：

节点按必要次数展开，不要求每次写全身体感觉、思想、台词。可以先从人物选择推导情绪，再校准读者体验。

## 五类功能按需选

| 功能 | 何时使用 | 完成条件 |
| --- | --- | --- |
| 过场 | 时间、地点或视角需要转换 | 新位置与必要状态清楚，承接未完成行动；可用概述 |
| 铺垫 | 后续选择需要人物、资源或关系依据 | 细节当下有意义，后续可回看；不一次倾倒背景 |
| 积蓄 | 读者已在乎结果，需要加深利害或期待 | 新信息改变判断或压力，不重复同一种受辱 |
| 对峙 | 不同目标无法同时满足 | 人物试探、让步或行动改变双方选择 |
| 爆发／兑现 | 前面承诺进入结果 | 核心选择生效，结果及反应落地 |

这是功能分类，不是固定顺序。一场可承担多种功能，也可用安静的关系变化完成兑现。

## 环境、对话与篇幅

环境可定位空间、约束行动、提供信息、表达关系、承载情绪、留下后续用途。按功能选细节，不按人物数量决定景物字数。路人的小动作可建立生活感；进入关键因果的人物应有自己的目的，不只作为主角的捧哏。

台词先问人物在做什么：试探、拒绝、隐瞒、安抚、索取还是承诺。视角人物先听声后转头，可先给台词再给动作；注意力已在对方身上，可先给动作再给话。这是注意力顺序，不是句式铁律。内心愤怒的人可以故意温和地说话，潜台词由处境与行为支撑。

展示适合关键选择、关系转变、证据与兑现；概述适合重复劳动、路程、时间跨度和必要背景。同一场可混用。检查扩写增加了什么体验、压缩是否省掉关键因果，不按“展示永远更好”评判。

## 完整小例：安静也能推进

承诺：母亲终于能决定什么时候休息。她的顾虑：不能失信熟客；儿子的误区：以为有钱就能替她安排。场景限定为收摊时，已有检查费，不添加病情恶化。

节点一：儿子看到未交鞋的取货条，发现停摊不仅是钱的问题。节点二：母亲自己打电话改约，儿子忍住插话。节点三：母亲把就诊日圈在日历上，要求下周只停半天；儿子接受并按此调整收送。

正文片段：

> 陈默把停业的纸拿到门口，母亲没接。
> 她抽出钱盒下面的取货条，拨通了电话：“王师傅，明天我有事，鞋给您送过去，行不行？”
> 陈默张了张嘴。母亲抬手示意他等等。
> 电话挂断，她拿过日历，把星期四圈起来。
> “先半天。”
> 陈默收起那张写着停业一周的纸：“好。我改送鞋的时间。”

结果是决定权与合作方式改变，温暖来自理解落实为行动；不需要按动作数加戏，不需要下一刻丢钱。后续可以是执行共同安排的期待，也可以在此温暖收束。

## 渐进练习与审读

1. 单元练习：同一刺激写两种不同性格的选择，检查能否凭行动分辨人物。
2. 场景练习：写一个目标与阻力，让结尾状态确有变化；再写一个低动作密度但关系改变的版本。
3. 详略练习：同一事件分别写概述和展开版，标明各自保留、丢失的信息与体验。
4. 信息练习：保持客观事实不变，分别写成期待结果、追问原因或意外重释，检查视角是否作弊。
5. 单元练习：串起数场，完成一次承诺，再让结果产生后续；连读查重复与余韵。

练习可临时限字或限动作帮助聚焦，交稿判断回到因果、可理解性和体验，不升格为作品配额。反馈问“读者实际读到了什么”，不要求复述作者设定的情绪。单次模型样例不能证明质量稳定提升。
