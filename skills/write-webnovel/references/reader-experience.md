# 阅读承诺与连载

本文件是来源研究与编辑经验的综合操作法，不是平台算法或经实验证明的追读公式。证据等级见 [提炼依据](sources.md)。

## 先确定阅读承诺

用一句话描述：读者期待谁通过什么独特方法，逐步获得什么结果与体验。分别确认内容承诺（破案、经营、关系发展等）与调性承诺（幽默、温暖、恐惧等）。按当前任务已有信息确定，不机械追问；平台、男女频、标签不能代替具体受众。

| 主要期待 | 可感进展 | 常见假进展 |
| --- | --- | --- |
| 成长升级 | 新能力改变解决问题的方式和选择范围 | 数字上涨，办法不变 |
| 经营种田 | 资源转化、生产改善、生活被改变 | 只有账目与规模 |
| 恋爱关系 | 理解、信任、主动付出和边界改变 | 误会循环，关系复位 |
| 悬疑探索 | 证据改变解释，解释改变行动 | 只加谜题，不答旧问题 |
| 喜剧群像 | 人物欲望碰撞产生独特办法与后果 | 可替换姓名的段子 |
| 日常治愈 | 愿望实现、关系加深、生活体验 | 安静却没有新的认识或体验 |

开篇建立感知锚点、利害关系、行动方向与类型体验。不要求同段齐备或固定字数出现金手指；尽早给一次真实的小体验，不能只预告未来精彩。控制同时出现的陌生名字和规则，以理解当前选择所需为准。

## 节奏：进度与承诺匹配

分别检查进度、信息、展开程度和情绪强度。打斗很密仍可能没有进展；安静交谈也可能改变全部判断。用“本段承诺—实际推进—所用篇幅”定位拖沓，不能按动作数量裁决。

全书规划核心问题、主要关系和终局变化；卷规划阶段目标、阻力、关键选择及结束状态；当前故事规划场景因果与信息顺序。远期细节可调整，已写结果和能力依据不能随意改写。

高潮后保留成果使用与余韵。之后可以转向新愿望、责任、关系或机会，不必更危险。判断缓冲场景是否仍有值得体验的内容，而不是要求每章强刺激。

## 信息与章界

| 机制 | 读者的问题 | 写作检查 |
| --- | --- | --- |
| 期待 | 想看的事何时发生？ | 结果是否有价值，有没有真实进展？ |
| 悬念 | 重要结果会怎样？ | 是否在乎人物、办法和代价？已知主角大概率获胜仍可成立 |
| 好奇 | 已发生的事为什么如此？ | 已提供足够信息，让缺口可辨认，而非只堆陌生名词 |
| 惊讶 | 为什么偏离我的判断？ | 新解释能否回看旧证据？不能为反转取消既有事实 |

场景组织因果，章节组织阅读停顿与再次进入。章界可落在决定、新发现、关系变化、兑现后的新机会，也可温暖收束。分别检查“这一章值得读吗”和“读完想继续吗”；悬崖结尾不能替代本章内容。维护作者、读者与每个人物各自的知识边界，避免为悬念故意遮住视角人物正在明确思考的关键事实。

## 兑现不是宣布结果

解除压力、获得能力、得到认可、建立连接、恢复意义都是可选回报。结果要进入生活：获胜后使用资格、伙伴据具体贡献改变信任、受保护者重新获得选择。配角反应应符合自身利益，不全员只负责惊叹。压抑不必越强越好，支线甜头不自动抵消核心承诺的破坏。

## 反馈与连载交付

| 反馈 | 处理 |
| --- | --- |
| 事实或连续性错误 | 核对证据，修正文与后续依赖 |
| 看不懂 | 检查信息次序、指代、视角与知识边界 |
| 重复、准备太久、不兑现 | 对照承诺与实际进度检查结构 |
| 希望人物必须赢或关系必须这样发展 | 判断是否违背作品承诺，不自动服从评论 |

读者评论有样本偏差。后台若提供数据，区分开篇继续阅读、章节流失、更新回访与实际付费；同时考虑流量来源、题材匹配和更新间隔。一次波动不能证明某技巧有效或失效。试读可问：你在等什么、哪里困惑、哪里想跳、记住谁因为什么；记录原文位置与反馈，勿诱导读者认同作者解释。

稳定更新与存稿用于履行交付约定，不保证推荐和收入。写完、送审、定时发布、实际公开分别管理，为审核与修订留余量。写作授权不包括发布授权。
