# 开源交付检查

只在用户要求开源就绪审计或首次公开发布时展开；普通内部版本不强制执行全部项目。

- 授权：README 声明、LICENSE、包元数据与第三方资源授权是否一致。没有明确许可证时标记待决定，不替用户选择或更改法律授权。
- 从零使用：在干净副本按 README 安装、配置、构建和运行；检查 monorepo 清单、编译嵌入资源、容器上下文与真实发布包是否齐全。
- 默认暴露：测试默认监听、管理接口认证、示例密钥、公开响应中的敏感 URL 和调试配置；仅测试获授权环境。
- 持续验证：现有 CI 是否覆盖主要安装和使用路径，是否依赖维护者本地文件；没有 CI 与功能失败分开报告。
- 维护入口：问题反馈、贡献约定、支持平台和已知限制是否准确；不为小项目强加复杂治理文件。

输出按项目列出可复现问题、证据、影响与发布阻断原因。技术交付通过不代表许可证法律审查通过，也不包含营销分发或联系社区成员。
