# 写书

把一个值得展开的问题写成有连续阅读价值的书：每章推进认识或行动，每部分改变读者处理问题的能力。方法来自祝融说理论书、实践书与叙事作品的抽样阅读，不意味着所有新书都要使用 RC 哲学或原站点格式。

## 先确定写的是什么

从用户要求和现有稿件确定主题、目标读者、核心问题、希望读者发生的变化、范围、语体及本次交付量。已有答案不重复询问；可推断的小项注明假设。主题缺失或存在会改变整本书方向的歧义时，只问关键缺项。

- **规划新书**：交付定位、主线和带章节职责的目录。用户只要大纲时，不扩写全书。
- **撰写新书**：先形成足够指导正文的结构，再继续完成授权的正文；不要把提纲当作整书交付，也不要设置逐章审批关卡。
- **续写或重写**：先读目标书的介绍、目录、已有代表章和相邻章节，确定本章承接什么、新增什么、把什么留给后文。明确用户要延续的版本，不用旧稿覆盖当前工作稿。
- **整书修订**：先找论证缺口、重复章节、术语漂移和承诺未兑现处，再按影响修改；不要仅做逐句润色。

选结构和语体时读 [写作路径与样本](references/writing-patterns.md)。在祝融说仓库落盘时另读 [仓库约定](references/repository.md)。不在该仓库写书时，直接交付用户要求的文稿格式。

## 让全书有一条推进线

用一句可讨论的判断表达全书主张，再说明它回答什么问题、在哪些条件下成立。为各部分安排不同职责，例如建立解释工具、检验工具、处理边界、落实行动；顺序服从主题，不固定篇数、章数或字数。

为每章保留一张简短的工作卡，可在工作笔记中记录，不必出现在正文：

- 本章要回答的具体问题，以及相较前章的新增判断。
- 依赖的概念；推动判断的推理、材料或场景。
- 最重要的反例、失效条件或尚不能确定之处。
- 读者读完能理解或做出的变化，以及下一章真正需要解决的问题。

如果两章的答案和材料可互换，先重新分配职责。理论书不能只有立场宣言，实践书不能只有行动口号，叙事书不能靠人物轮流宣讲理论。

## 写出完整章节

选择与目标书一致的入口：具体情境、概念难题、已知方法的失效或人物面临的选择。入口提出的困难应在本章内得到实质处理。

以连续段落展开推理。引入术语时给出含义、在此处解释的现象及使用边界；例子之后写清它支持了哪一步判断。用表格比较条件，用清单组织操作，不把整章压缩成提纲。保留原书合适的修辞节奏，但让比喻解释机制，不替代机制。

- 理论章节：区分作者的哲学设定、推论、经验事实与价值判断。回应最有力的异议，不凭相似比喻断言理论获得科学证明。
- 实践章节：给出使用条件、具体动作、可见产物或判断标准，并解释失败后如何调整。工具、代码和练习按主题需要加入，不要求每章都配一套。
- 叙事章节：通过行动、对话、后果和关系变化推进；保护人物视角、知识边界、时间线与世界规则。

章末兑现本章问题；确有依赖时才引出下一章，不机械使用“旅程刚刚开始”等预告。导论讲清阅读契约，结语回应全书起点并保留已论证的开放问题。附录承接正文需要的工具或资料，不用来填补核心论证。

## 控制跨章一致性

跨章或整书任务维护一份轻量写作记录，包含：定位与目录、术语定义、重要判断及适用边界、案例用途、已完成章节和待处理问题。优先复用项目已有记录，不为单章短任务制造一套项目文件。

续写前用记录定位，再回读有关原文；摘要不能代替关键段落。概念在首次需要处解释，后文发展它而非重新讲同一套定义。重用案例时必须增加新视角或新信息。调整核心概念后，检查依赖该概念的章节和结语。

若整书无法在当前交互内完成，将已完成的正文和准确进度保存到用户工作区，标出下一处可继续写作的位置；如实说明剩余内容，不以缩写章节、占位文本或目录冒充完成。

## 核对材料与交付

真实引文、数据、案例和具体研究结论应可追溯；技术、政策等易变信息按任务需要核对并注明时间或版本。未核实材料不写成确定事实。虚构、合成案例和思想实验在非虚构书中明确标识，不冒充作者亲历、真实访谈或调查。样本书是写法参考，不自动成为事实权威。

交付前回看本次相关章节：

- 全书承诺是否落到正文，本章是否有独立贡献？
- 关键结论有无跳步、循环论证、范围扩大或与前文冲突？
- 案例是否支持判断，术语、人物和引用是否前后一致？
- 实践方法能否执行，叙事变化是否有因果，结尾是否真正处理开头的问题？
- 是否有未完成占位、重复总结、为凑篇幅添加的比喻或空泛段落？

交付用户所要的正文或文件，并简短说明完成范围及仍需核实的实质问题。写作任务本身不包含发布、部署或向他人发送书稿。
