# 写作路径与样本

以下来自 2026-09-07 对祝融说目录、选定章节开头/中段/结尾及导读的抽样，不是全库逐章审计。路径相对祝融说仓库根目录。样本说明可借鉴的组织方式，不规定新作品必须同样措辞或持有同样立场。

## 理论书：问题 → 概念 → 机制 → 边界 → 实践含义

`data/books.yaml` 中，《实在建构》按存在、认知、秩序、实践展开；《词语的呼吸》从语言如何形成共识，进入公共危机、权力运作与有意识的使用。这类递进的价值是：先建立读者需要的解释工具，再用工具处理更复杂的问题，最后回答如何生活或行动。

代表原文：

- `content/books/volume-1/reality-construction/part-01/chapter-01.md`：从开端难题引出“可能性基底”，再与物理学和哲学传统对话，最后引出“观察”问题。借鉴概念之间的依赖关系；其量子类比和“印证”措辞不应直接当成科学证据使用。
- `content/books/volume-2/the-breath-of-words/part-02/chapter-04.md`：从前章的共识形成进入语境污染、语义极化、回音室和犬儒主义。借鉴机制的关联与章节承接；宏大危机修辞、绝对化判断需要按材料强度收敛。
- `content/books/volume-5/reality-hijacking/part-01/chapter-01.md`：以共享工作室的关窗争议作为明确标注的思想实验，区分经验、解释、责任和程序；保留其他可能，区分一次争执与持续模式，末尾说明边界并给出来源脚注。适合需要克制分析、概念辨析的作品。这是当时的重写草稿，不代表全库唯一风格。

写作判断：不要只将“收敛”“评估权”“可用余量”等词贴到新主题上。若沿用 RC，先查目标书与当前理论原文的定义，再解释该概念在此处增加了什么解释力；若用户未选择这一体系，使用适合主题的框架。

## 实践书：困境 → 机制 → 方法 → 可用产物

`data/practices.yaml` 展示了多种组织尺度：《数据即边界》从字段、表到系统边界及治理；《长线内容》从服务验证到产品化和会员；《有效约束》从协作认知到架构、流程、环境、质量与综合案例。分部顺序由真实依赖决定，不只是并列知识分类。

代表原文：

- `content/practices/season-4/data-as-the-boundary/part-01/chapter-01.md`：以线上事故、具体代码和字段承担多重含义的问题建立必要性，再解释概念压缩与认知成本。借鉴从可见症状逐层追到设计选择；自行编写类似场景时注明示例性质。
- `content/practices/season-4/long-term-content/part-02/chapter-03.md`：围绕服务定义、定价和交付边界组织一章，结尾连接到产品化。借鉴商业步骤之间的输入输出关系；原文中的比例、收入数字和承诺不作为新稿事实直接复用。
- `content/practices/season-5/effective-constraints/part-01/chapter-01.md`：从 AI 编程的预期落差重新定义协作角色，章末提供角色分工卡。借鉴“理解变化后有可使用产物”的教学闭环；对模型能力和技术建议按实际版本核对。

可用的章卡示例（演示结构，不是来源原话）：

> 问题：为何一个用户状态字段不断引出新分支？
> 新增判断：生命周期、权限与风险是可独立变化的维度，合并存储会让隐含组合进入代码。
> 材料：一个明确标注的示例表、两次需求变化、拆分前后的含义对照。
> 边界：数据拆分引入迁移和一致性成本，不能用“多建表”替代业务判断。
> 产物：读者列出一个现有字段承载的不同含义，判断哪些值得分离。

## 叙事作品：人物困境 → 选择 → 后果 → 新张力

不要因文件位于 practices 就将作品写成教程。

- `content/practices/season-7/persona-and-performance/prologue.md`（《人戏：代价》）：通过苏三、陈默、老何的场景和对话，让成功、自我与代价成为冲突，结尾保留人物选择的后果。借鉴主题由剧情承载、角色立场相互碰撞；延续时先读取现有人物和世界规则。
- `content/practices/season-7/a-frightened-bird-at-the-sound-of-a-bow/part-01/chapter-01.md`：以咨询对话组织观念清单，展示“看见自己的解释结构”的转变。可借鉴案例与分析交错，但不能据此把虚构对话标为实际咨询记录，也不能将故事结果当成普遍疗效证据。

## 导读的辅助作用

`content/books/volume-1/reality-construction/guide/index.md` 提炼了主张、读者困惑、章节地图、易误读点和收获，适合快速定位阅读路径及检查“读者会怎样理解”。导读是辅助地图；续写、引用或解决矛盾时回到正文。只有用户需要导读时才生成，不把它加入每本书的强制交付物。
