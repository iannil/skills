# 实验协议与结果判定

执行前保存以下实际选择，不要求固定运行次数或固定难度区间。

| 项目 | 记录内容 |
| --- | --- |
| 主张 | 学习改善哪类任务、迁移到什么新条件 |
| 固定项 | 运行时、模型、工具权限、每任务预算、环境与提示版本 |
| 自变量 | 哪些资产或学习机制发生变化 |
| 题包 | 训练／开发／保留题划分、任务族、哈希、验收器版本 |
| 样本安排 | 配对方式、独立任务数、每题重复次数、组别顺序 |
| 主要指标 | 成功判据、实际意义阈值、成本或退化限制 |
| 有效性 | 泄漏、截断、协议违规、环境故障的处理规则 |
| 预算 | 单次及累计调用限制、已知与未知费用、停止与恢复点 |

## 不混淆样本与尝试

同一任务的多次运行不是多个独立任务。按任务及任务族报告配对差异，保留重复运行的波动；有统计分析时采用适合配对和聚类结构的方法，并解释区间而非只报均值或显著性。样本规模依据变异、目标效果和预算确定，不能承诺某个固定次数足够。

“学习组优于空资产组”尚不能排除上下文长度、提示变化等因素。需要内容特异性证据时再与无关资产组比较。收益主张、效率主张和无退化主张分别判定，不把成功率提升自动解释成净收益。

## 验收器先于模型试跑

用已知正确、错误、缺失输出和边界样本检查验收器。检查它是否只认某种字符串而拒绝正确等价解，是否接受空目录、旧输出或任务自报成功。对“未运行”返回明确未知状态，不算通过。

## 停止与恢复

预算到限、费用无法可靠约束、环境大面积失效或评测泄漏时停止依赖运行并保存证据。短暂故障可在事前重试预算内恢复；改变题目、运行时或判据应另开版本。达到预定样本后停止，不依据结果好坏无限追加直至显著。
