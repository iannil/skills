# 经济模型与口径

使用这些公式前先确定计价单位、收费周期和用户分母。年费模型只是一个可选模板；按次、服务型、双边市场不得强塞年付假设。

## 输入纪律

每个输入记录：值、单位、周期、来源或“假设”、范围及最敏感的不确定性。

- 收入：标价、折扣、每客户使用量、税是否含在价内、实际收款时间。
- 变动费用：支付费、退款、AI/计算、存储/带宽、采购/履约、直接客服劳动、免费用户分摊。
- 固定费用：工具与基础设施、非逐客户的劳动报酬。客服与创始人固定劳动不要重复计入。
- CAC：渠道现金及销售/创始人时间，除以真实新增付费客户；不可除以注册数。
- 留存：客户续费率、收入留存、月流失和年流失不可混用；短期活跃不能冒充年续费。
- 初始投入：研发、导入工具、内容、启动费用；与持续盈余分开。

无法量化的输入不填零；给合理区间及其依据，或者说明模型暂不能支持投资判断。变量可能联动：提价可能降低转化并增加服务期望，降低免费额度可能损害激活。

## 年付订阅的稳态简化模型

适用：每客户每年一次收款、无复杂扩容、规模稳定。设：

- P：年费；f 和 b：每笔支付比例费及固定费；q：退款金额占收入的准备比例。
- v：每付费用户的月度服务费用，含免费用户成本分摊。
- r：年客户续费率；A：每位新增付费者 CAC。
- F：月固定费用与非逐客户劳动；N：平均服务的活跃年付用户。

```
获客前年度贡献 C = P - (P*f+b) - P*q - 12*v
稳态补客费用/客户/年 = (1-r)*A
补流失后的年度贡献 S = C - (1-r)*A
稳态月盈余 = N*S/12 - F
平衡付费用户 = ceil(12*F/S)，仅 S>0 时存在
新客户首个完整服务年的贡献 = C-A
```

退款后是否返支付手续费、年中退款的服务费用要按供应商条款修正。固定费随规模跳升时改用分段模型。S≤0 时不要输出负的平衡人数，要说在这些假设下扩大规模不能达到平衡。

这是收入费用摊销后的稳态口径，不是现金余额、第一年销量或增长计划。快速增长时须按批次计算收款、服务义务、流失及新增获客；未交付年费不能视作全额可支配利润。

## 获客反推

```
初始目标的合格试用数（忽略流失）= 目标付费人数 / 合格试用转付费率
稳态年补客量 = 目标付费人数*(1-年续费率)
稳态月合格试用量 = 年补客量 / 12 / 合格试用转付费率
网站访客 = 合格试用量 / 访客转合格试用率
```

必须说明“合格”的行为定义；访客转试用率未知时不能把合格试用量称为网站流量。创始人挑选、协助的小样本与自助漏斗分别统计。

## 其他模式

- 月付：按月贡献、月流失和付款手续费建模；年留存换算仅在恒定风险假设下可用 `(1-月流失率)^12`。
- 按次/服务：每单净收入减交易、采购和交付劳动，再检查可交付产能、复购和渠道费用。忽略产能的高销量情景无意义。
- 一次性软件：首次收入要覆盖未来维护/支持义务；不要用一次性收入承诺无限期云成本。
- 佣金市场：先从交易额得到平台实得收入，再扣补贴、争议、履约与获客；GMV 不是营收。

无足够成熟的留存数据时，不提供看似精确的 LTV/CAC。可以给明确假设下的范围，并优先观察首年贡献和回收期。

## 交付核验

用可运行脚本或可检查的电子表格计算。至少核对一个基准点及无平衡点的压力情景，确认报告与文件数值一致。输出输入和公式，不只给数字截图。敏感性至少覆盖价格、CAC、支持/用量成本及留存中的关键变量；解释哪些组合现实上难以同时成立。
