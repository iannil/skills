# 商业定位与价值验证

交付两个分别给出、经过反证检验的判断：商业成立已有多少证据，以及下一阶段是否值得投入。说明为谁、在什么任务中、提供什么可收费结果，为什么能胜过现有解决方法，以及在什么条件下值得投入。定位寻找与商业价值调研是同一项工作，不能先推荐定位、等用户追问才检验。

## 决策底线

- 不保证未来盈利。**证据成熟度决定可以声称什么；下一步的成本、可逆性、潜在收益与学习价值决定是否值得投入。** 可以推荐验证尚未证实商业价值的方向，也允许没有值得采取的行动；不为满足数量包装结论。
- 缺少当前阶段尚不应产生的付款或留存数据，不是负面证据。逐项区分支持、反对与未知；未知应转化为验证任务，不能自动等同于价值不足。若经过适当测试仍未出现预期行为，须记录测试覆盖与局限，才可作为相应假设的反证。
- 区分“需求存在”“有人为这类需求付钱”“会为本产品另付钱”“能够长期盈利”。不能跨级推断。
- 允许推翻自己或用户先前偏好的方案；用户指定方向时先审查该方向，不擅自替换产品或扩大到无关行业。
- 报告必须展示反证、已有工具足够好的情况、尚未解决的不确定性和判断被推翻的条件。
- 调研授权不包含联系受访者、发送营销消息、购买服务、投放广告、上线收费或修改应用代码。可以形成具体实验方案，不虚构执行结果。

## 1. 理解资产与经营目标

先读用户提供的产品、代码/文档、既有定位及可访问的实际数据，区分现有能力、规划能力和演示。识别客户、地域、收入方式、创始人可投入时间与分发资源。缺少关键目标时可问简短问题，同时完成独立研究；普通细节可采用明确标注的假设，不重复索取已有信息。

先确认本次决策是探索、原型/付费试验、小规模商业化还是扩大经营，并记录可承受的时间、现金损失及不可逆承诺。未指定时按项目阶段提出投入边界，并标为待确认假设。不要用扩大经营所需证据阻止低成本探索，也不要用探索线索支持扩大经营。

不要把埋点代码当活跃数据、SEO 页面当有效流量、现有流量当目标客户。没有实际分析权限或资料时明示缺口。

若用户给定定位，先将其写成可证伪的假设；若要求寻找方向，基于资产提出少量实质不同的候选，通常 2–4 个。区分用户、任务或买单逻辑，不能只是改几个形容词。

候选格式：**为［具体买单者/使用者］在［触发场景］解决［可观察问题］，相较［当前方法］提供［可衡量结果］，以［收费方式］收费，经由［可触达渠道］成交。**

## 2. 联网研究并主动寻找反证

使用当前可用的联网检索和网页读取工具核实动态事实，即使对象知名也要核对关键功能、价格和状态。无联网能力时交付明确标注的有限资料评估，不能声称完成深度调研或核实未查证事实；仍可依据现有资料提出条件性的探索建议，并披露资料限制。

每个候选先做初筛：真实任务、实际替代、付费线索和可触达路径。只凭明确反证、致命约束或有依据的不合理投入代价淘汰，不因缺少成交或公开资料淘汰；将关键未知列为验证任务后深挖幸存者；每个淘汰结论保留理由及来源，避免只研究最喜欢的候选。结论不足时缩窄人群或考虑依附现有工具的方案，仍须重新检验，不无止境发明新方向。

建立来源台账，记录 URL、标题/发布主体、访问日期、内容日期、所支持的具体论断、取得方式（正文/仅摘要）、局限和冲突。研究停止条件是关键问题已覆盖、继续搜索主要重复，或剩余问题必须靠实验回答；来源数量本身不是充分性标准。

四条证据链都要覆盖：

1. **任务与代价**：第一人称工作方法、真实抱怨、迁移原因、损失或耗时。追查当前如何绕过、多久发生一次、是否值得改变习惯。保留“不需要”“从不用”“已解决”的负例。
2. **替代品与差异**：直接竞品、免费工具、通用工具组合、手工/外包以及不解决。优先核对官网、帮助文档、定价和状态；查清套餐、地区、隐私及许可差异。“没找到”不等于“没有”。宣传页不等于实测，Coming Soon 不等于已成交。
3. **付费与结果**：区分口头意愿、竞品购买、自身试付、重复购买、续费及可验证收益。竞争者营收要注明自报/独立核验、日期、统计口径；没有营收就不猜 MRR。
4. **经营与分发**：用户能否以可承受成本触达、导入与学习成本、服务劳动、供应商费用、平台依赖、长期维护。成功案例与失败/取消订阅案例同时检索。

关键主张尽量用相互独立的证据交叉验证；多个转载或同一官网不同页面不构成独立需求验证。论坛是方便样本，不能从帖子数量推算市场比例。只有搜索摘要时注明，并避免让它独自承担核心推荐结论。

来源冲突时，区分访问时间和内容时间，优先核查原始资料及实际口径；无法解开就保留冲突、降低置信度。引用附近附直达链接，短引用遵守来源限制，不靠堆引用掩盖缺少关键证据。

## 3. 检验价值机制、机会与商业潜力

区分已核实事实、相邻市场类比、分析推断及待验证假设，回答以下问题：

- 为什么现在可能成立？检查技术、成本、用户行为或采购条件的变化，以及过去阻碍采用/交易的条件是否被移除。变化线索不等于购买证据；类比要说明相似点、差异与迁移前提。
- 若关键假设成立，能产生多大的客户净收益与经营收益？说明从条件变化到客户行为再到收入的因果链，并指出最可能断裂的位置。不能仅凭新颖、宏观市场规模或乐观情景认定潜力。

- 买单者是否明确？是组织采购、专业个人还是普通消费者？不能把职业用户自动叫 B2B。
- 现有方法的总代价是什么？新方案净收益需扣掉导入、学习、维护和纠错。省时有价值不等于用户愿意新增订阅。
- 用户为什么现在切换？作为替代品需覆盖哪些原有能力，作为补充品能带来多少增量价值？不能同时享受“省掉旧订阅”的收益又不承担替代成本。
- 哪个差异直接改变购买或留存？语义搜索、AI、模板、隐私和基本出处能力若已普及，只是基础要求。使用历史、数据积累或网络效应需要行为证据，不因概念好听就认定护城河。
- 价值是否持续发生，还是只在一次项目中出现？据此考虑订阅、按次、按项目或一次性收费，不强行订阅化。
- 能否说明第一批合格买家如何被识别与触达？社群、SEO 和口碑不是零成本渠道，创始人时间必须计入。

没有可靠交集分母时不输出伪精确 TAM。宏观创作者/中小企业人数不能直接乘价格。改用可识别客户群和自下而上的获客情景，区分访客、合格试用、激活、付款与续费。

## 4. 计算可持续经营条件

阅读 [经济模型与口径](references/economics.md)，选择匹配实际收费方式的模型。按决策阶段选择精度：探索/原型试验阶段先反推成立所需的价格、成本与可达客户条件，并估计验证预算和最大损失；商业化或扩大经营时，至少比较压力、基准假设、有利三种一致口径的情景。“基准”不代表最可能预测。

把事实参数、待测参数分开。输出可复算的输入、公式和 CSV 或计算文件，核对单位、金额、百分比、四舍五入和盈亏平衡结果。不能沿用示例产品的价格或续费率作为行业默认值。

报告按当前决策需要解释价格、使用成本、支持成本、获客及适用时的留存敏感性；标明创始人劳动、一次性研发、税费和增长投入包含哪些。经营算得通不能代替真实购买证据，但在假设透明、损失可控时可支持验证投入；能否扩大经营仍需对应阶段的实际数据。

## 5. 双轴决策：证据成熟度与下一步投入

对每个候选检查需求、净增量、支付逻辑、获客、经济条件和交付能力，逐项写“支持/反对/未知”和依据。不用总分抵消致命约束，也不要求早期候选所有项都已验证。

**先回答商业成立已有多少证据。** 分别报告任务线索、品类支付、本产品支付、重复价值及可持续经营的证据和缺口，不压成单一分数。高度同构报价可增强迁移判断，须说明差异，不能冒充本产品成交。长期订阅披露留存观察窗口；一次成交或短期试点不能证明长期盈利。按次或一次性收费以对应的购买、交付及维护义务判断，不强加订阅续费门槛。

**再回答下一步是否值得下注。** 衡量价值机制是否可信、潜在收益、现金与时间损失、可逆性、机会成本，以及实验结果是否会改变决策。不给缺乏依据的成功概率或伪精确期望收益。预算小本身不构成推荐理由：实验必须检验重要假设，并有可执行的取证路径。

| 下一步决策 | 必要依据 | 输出边界 |
| --- | --- | --- |
| 推荐低成本探索 | 问题与价值机制具体，有可追溯的机会线索或明确标注的用户线索；无已知致命约束；能在可承受成本内澄清关键未知 | 可无本产品付款、留存或成熟市场数据；明确尚未验证，指定要检验的假设与投入上限 |
| 推荐原型或付费试验 | 目标人群的问题线索和差异假设可信，试验对象可触达，最小方案能够检验采用/支付或关键交付条件，成本与损失可控 | 可无成交；允许为实验建设必要的最小功能，不借验证名义展开完整产品建设 |
| 推荐小规模商业化 | 有与目标人群匹配的本产品支付/付费试点依据，交付可行，初步经济条件合理；关键未知能在受限经营中检验 | 限定客户范围、预算及交付规模；缺少长期数据时不宣称可持续经营已证实 |
| 推荐扩大经营 | 有与商业模式及观察周期匹配的持续价值、获客、成本和交付证据；经济条件成立；关键规模化风险已处理或受控 | 指定扩张边界与监测条件，不能承诺成功 |
| 暂缓，先补具体信息 | 关键未知目前无法低成本检验，或缺少可触达对象、实验资源，暂不能设计有决策价值的行动 | 说明阻塞信息和恢复条件，不将其表述为商业模式已被证伪 |
| 停止/淘汰 | 有明确反证、不可处理的现实约束，或相对潜在收益及替代机会，验证/经营成本不值得承担 | 写清反证适用范围和什么新证据会改变判断；已有免费方案只有对目标细分任务足够好、且无可信增量时才支持否定 |

推荐以当前证据支持的下一步为限。证据成熟度低可以同时得到“商业成立尚未证实”和“推荐限额验证”；已有成交也可以因交付亏损或机会成本得到“不值得继续投入”。

没有候选达到商业化门槛时，分别写清“本轮尚无足够证据支持商业化/扩大投入”与“哪些候选值得探索或验证”。只有没有任何值得采取的下一步时，才输出“本轮没有值得投入的行动”，并区分反证淘汰与暂缓取证。

## 6. 输出报告及最小验证方案

按 [报告交付规范](references/report.md) 输出可审阅的 Markdown 报告、来源台账和测算材料，默认保存到用户项目的合适文档目录；没有文件工具时在对话交付完整内容。不擅自覆盖已有研究或修改产品计划，把修正建议写入新报告。

为当前阶段最影响决策的未知选择最小实验，不要求每轮完成所有验证。探索可采用任务观察、问题访谈或关键能力原型；支付假设用统一报价或付费试点检验；持续经营假设再检验重复使用/续费与独立渠道。记录实验能证明和不能证明什么，避免只收集点赞、口头支持等不能区分假设的信号。设置与产品成交周期匹配的时间/预算上限、可承受损失、继续和停止条件，以及结果不确定时的处理方式；数字是团队决策阈值，不能当行业标准。不要套用固定“20 人/5 付款/六周”，更不能将早期高接触转化率外推为自然流量转化。

最终摘要先分别给“商业成立证据”和“下一步投入建议”，再给最强支持、最强反证、关键经济条件、缺口和报告链接。明确哪些原先判断被修正，以及没有完成的访谈、实测或收费验证。
