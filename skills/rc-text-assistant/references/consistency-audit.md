# RC 理论延伸一致性审计

先确认用户指定的总纲和版本。现行原文优先于旧摘录的解释；引用保留准确出处，原文缺失则标待核，不用记忆编出公理编号。

对目标段落分列四层：原始命题、理论内推论、跨到新领域的桥接假设、需要外部证据的经验判断。价值选择和比喻另行标明。判断内部一致性不意味着认可外部经验结论。

检查概念是否换义、前提是否足够、推论是否越界、总纲的适用限制是否保留。新的推论可作为作者发展，只要说明新增前提；不能冒充总纲原话，也不因为新就判为错误。

涉及科学、社会或技术事实时独立核验；“观察”“熵”“收敛”等词相似不构成科学证明。不要用主流接受度代替论证，也不要用体系自洽代替实证。

交付“目标位置—命题类型—原文依据—新增前提—问题—修订建议”。只要求审计时不改正文；授权改稿时保留有效论证与语体，并复查翻译和依赖章节。整书结构审计可结合可用的 book-content-audit，避免重复两套发现清单。
