# AI 编辑器架构参考

仅用于包含持续编辑与 AI 生成的产品。先确定正文、来源、候选、版本和运行任务的所有权及生命周期，而非先选择富文本组件。

- 正文有明确版本标识；AI 候选绑定起始版本与来源快照。接受时检查冲突，保留人工修改。
- 流式输出绑定运行 ID、文档 ID 与位置；取消或切换后拒绝迟到事件。区分生成游标与成功保存游标，保存失败不得推进完成状态。
- 来源更新形成新版本，既有引用仍可追溯到生成时材料；不能静默替换历史证据。
- 版本恢复形成可追溯的新修订；历史导出读取指定快照，不需先恢复覆盖当前正文。
- 模拟适配与真实服务共享契约，分别声明已实现交互与未验证外部能力。

按产品需要选择整章候选、局部补丁或协作方案，不强制引入实时多人编辑。交付状态机、冲突规则、持久化边界和异常场景；具体实现由正常开发流程处理，验收可使用 engineer-qa 的专项场景。
