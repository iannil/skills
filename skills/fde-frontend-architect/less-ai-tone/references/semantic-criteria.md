# 语义层判据（四项）

先跑：

```bash
python3 scripts/detect.py <文件> --candidates --out <候选.json>
```

对每条候选只从下列封闭标签中选一个，并写 `label` / `confidence`（高/中/低）/ `reason`。

## 判断纪律

- 只按判据，不按「像不像 AI」的整体感觉
- 每条独立判断，不靠全文文风猜
- 拿不准选兜底标签；禁止自造标签

---

## 1. 同义重命名（段级）

同一实体/概念在段内换实义说法；代词与省略不算。

| 标签 | 判据 |
|---|---|
| 0组 | 全程同一说法，或只出现一次 |
| 1组 | 一个概念换了 1 次实义说法 |
| 2组 | 两个概念各换 1 次，或同一概念换 2 次 |
| 3组及以上 | 换说法连接 ≥3 次 |
| 无法判断 | 段落无法分析 |

改写方向：统一回原名词。不同实体碰巧近义、术语首次「又名」介绍、文学指称变化不改。

参考量级（研究语料）：约 0.5 次/段（人类）vs 0.8+（AI）；重灾段（≥2 组）人类约 8% vs AI 约 21%。

---

## 2. 衔接方式（段间接口）

看上段末句到下段首句。若句首有连接词，先检查其逻辑是否真成立。

| 标签 | 判据 |
|---|---|
| 表面有连接词实际关系不清 | 连接词逻辑不成立或勉强（优先） |
| 明确承接 | 同一对象/论述自然继续 |
| 有关但转换突然 | 同域但缺一步 |
| 主题跳转缺少说明 | 换到基本无关话题且无衔接 |
| 无法判断 | 上下文不足 |

统计：连续「明确承接」接口数为连环长度；≥6 连环重点报告。

改写方向：选 1–2 个接口改成自然跳跃；因果/伏笔接口跳过换下一个。教程/法律文书等要求紧扣的不改。

---

## 3. 冒号分类

按优先级命中即停：

| 标签 | 判据 |
|---|---|
| 引语或人物发言 | 人名+说/表示等引出言论 |
| 标题时间比例元数据或版式用途 | 版式/时间戳/比例等 |
| 定义或解释 | 术语后给定义或内容 |
| 空转提示 | 只宣布「下面有几点」+列举（**X，不改**） |
| 结论提示 | 冒号前独立明确结论，后展开（**真信号**） |
| 其他正文冒号 | 默认落点 |
| 无法判断 | 不足以下结论时慎用 |

只改「结论提示」类。

---

## 4. 高度同构三连

粗筛偏宽；判读只认骨架近乎逐字复刻。

| 标签 | 判据 |
|---|---|
| 高度同构 | 主谓宾及补充成分位置基本一一对应 |
| 部分同构 | 明显相似但未逐成分对应 |
| 只有词语重复句法不同 | 词重、句法不同 |
| 只有语义并列句法不同 | 内容并列、句法不同 |
| 无同构关系 | 无明显对应 |
| 无法判断 | 残缺或不足 |

改写方向：拆掉其中一句骨架，不删一项内容。刻意修辞、清单体、叙事三件事不改。

---

## 汇总口径

| 指标 | 计算 | 人类参考 | 报告门槛 |
|---|---|---|---|
| 同义重命名 次/段 | Σ组数 / 段数 | ≈0.49 | ≥0.7 或重灾段占比 >15% |
| 衔接连环 | 最长明确承接接口数 | 中位 ≈2 | ≥6 |
| 结论冒号占比 | 结论提示 / 正文冒号 | 相对较低 | 比例偏高列 B |
| 高度同构三连 | 「高度同构」计数 | 约占三连组 11% | 绝对数 ≥2 组列 B |

改写仍走 SKILL.md 白名单与确认流程。
